Kimi K3 是月之暗面于 2026 年 7 月发布的多模态推理模型，总参数量为 2.8T，支持文本、图像输入和 1M token 上下文。模型面向长程编程、知识工作与复杂 Agent 任务。

|  | Kimi K3 |
|----|---------|
| 总参数量 | 2.8T |
| 模型类型 | 稀疏 Mixture of Experts |
| 专家配置 | 896 个专家，每个 token 激活 16 个 |
| 注意力 | Kimi Delta Attention、Gated MLA |
| 深度信息流 | Attention Residuals |
| 输入模态 | 文本、图像 |
| 输出模态 | 文本 |
| 上下文窗口 | 1M token |

---

## 总体架构

K3 的主干由三部分构成：Kimi Delta Attention（KDA）处理长序列信息流，Attention Residuals（AttnRes）处理跨层信息流，Stable LatentMoE 扩展模型容量。SiTU、Gated MLA、Quantile Balancing 和 Per-Head Muon 用于增强训练稳定性与选择性。

Kimi Linear 是 KDA 的公开参考实现。其 Transformer block 在 KDA 与全注意力 MLA 之间混合，并在每个 attention block 后连接 MoE。K3 延续该技术路线，但将模型扩展至 2.8T 参数，并加入 AttnRes 与更高稀疏度的 MoE。

## Kimi Delta Attention

标准自注意力直接计算 token 两两之间的相关性：

$$
\operatorname{Attention}(Q,K,V)
= \operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

其训练计算量随序列长度 $n$ 呈 $O(n^2)$ 增长。自回归推理虽然每次只生成一个 token，却必须保留并读取全部历史 KV cache，因此缓存量和单步读取量都随 $n$ 增长。

### 矩阵值关联记忆

KDA 不保存每个历史 token 的 key 和 value，而是维护每个注意力头独立的矩阵状态：

$$
S_t\in\mathbb{R}^{d_k\times d_v}
$$

在快速权重（fast weight）视角下，$S_t$ 是一个矩阵值关联记忆，编码从 key 表征到 value 表征的瞬时映射。基础线性注意力通过累加秩一外积 $k_t v_t^\top$ 更新该映射，并以 query 对状态进行线性读出：

$$
S_t=S_{t-1}+k_t v_t^\top,
\qquad o_t=S_t^\top q_t
$$

历史信息由固定维度的矩阵状态表示，而非以显式 KV 序列存储，因此状态规模不随上下文长度增长。无约束累加缺少遗忘与修正机制；相似 key 对应的更新会在同一表示子空间内叠加，进而产生关联干扰。

### Delta rule：只写入预测误差

DeltaNet 将状态视为一组可快速更新的参数。对于当前关联 $k_t\mapsto v_t$，它最小化重建误差：

$$
\mathcal{L}_t(S)=\frac{1}{2}\left\|S^\top k_t-v_t\right\|^2
$$

对该损失执行一步梯度下降，等价于先让旧记忆预测当前 value，再只写入预测错误的部分。KDA 在此之前增加逐通道遗忘，完整过程可以拆成四步：

$$
\widetilde{S}_{t-1}=\operatorname{Diag}(\alpha_t)S_{t-1}
$$

$$
\widehat{v}_t=\widetilde{S}_{t-1}^\top k_t,
\qquad e_t=v_t-\widehat{v}_t
$$

$$
S_t=\widetilde{S}_{t-1}+\beta_t k_t e_t^\top,
\qquad o_t=S_t^\top q_t
$$

第一步按通道衰减旧状态；第二步检查旧状态对当前 key 已经记住了什么；第三步计算预测误差；第四步以学习率 $\beta_t$ 沿 $k_t$ 指向的地址写入误差。如果旧记忆已经能正确给出 $v_t$，则 $e_t$ 接近零，不需要重复写入；如果关联已经过时，更新会直接纠正它。

合并上述步骤可得到论文中的 KDA 递推式：

$$
S_t=
\left(I-\beta_t k_t k_t^\top\right)
\operatorname{Diag}(\alpha_t)S_{t-1}
+\beta_t k_t v_t^\top
$$

### 细粒度遗忘与位置感知

Gated DeltaNet 对每个注意力头只生成一个标量遗忘系数 $\alpha_t$，整个状态以相同速度衰减。KDA 将其扩展为 $d_k$ 维向量 $\alpha_t\in[0,1]^{d_k}$：每个 key 通道都有独立的保留率，可以同时维持长寿命记忆、快速更新记忆和介于两者之间的多种时间尺度。

旧 token 从位置 $i$ 传播到位置 $t$ 时，会连续经过中间 token 产生的状态转移矩阵。其影响由这些矩阵的累积乘积决定，因此“相隔多远”与“中间出现了什么内容”都会改变记忆强度。这相当于一种数据依赖、可学习的乘法位置编码。Kimi Linear 因而让全注意力 MLA 层采用 NoPE，将位置和近因偏置主要交给 KDA，而不是在 MLA 中加入固定频率的 RoPE。

### 特化 DPLR 与并行计算

KDA 的单步状态转移矩阵为：

$$
A_t=
\left(I-\beta_t k_t k_t^\top\right)\operatorname{Diag}(\alpha_t)
=\operatorname{Diag}(\alpha_t)
-\beta_t k_t\left(k_t\odot\alpha_t\right)^\top
$$

它是“对角矩阵减去秩一矩阵”的特化 DPLR 结构。对角项控制各通道的遗忘速度，秩一项执行与当前 key 相关的纠错。与一般 DPLR 分别学习两个低秩向量不同，KDA 将它们约束到同一个 $k_t$，减少了数值不稳定的除法和额外矩阵乘法。

自回归解码可以直接按上述递推式逐 token 更新固定状态。训练时若完全串行会浪费 GPU 并行能力，因此论文将序列划分为长度 $C$ 的 chunk：chunk 之间递归传递 $S$，chunk 内则用 WY representation 与 UT transform 将一系列秩一更新整理为矩阵乘法。论文实现取 $C=64$，单头训练 FLOPs 为：

$$
\operatorname{FLOPs}_{\mathrm{KDA}}
=6Td_h^2+3TCd_h+TC^2
$$

当 head dimension $d_h$ 与 chunk size $C$ 固定时，计算量随序列长度 $T$ 线性增长；全注意力的主项则为 $2T^2d_h$。

## Attention Residuals

PreNorm Transformer 的标准残差连接可写为：

$$
h_l = h_0 + \sum_{i=0}^{l-1} F_i(h_i)
$$

所有历史层均以固定权重 1 累加。模型加深时，hidden state 的模长持续增长，新层输出在累积状态中的相对占比下降，形成 PreNorm dilution。

AttnRes 将固定加法改为沿深度方向的 softmax attention：

$$
h_l = \sum_{i=0}^{l-1}\alpha_{i\rightarrow l}v_i
$$

$$
\alpha_{i\rightarrow l}
= \operatorname{softmax}_i\!\left(w_l^\top\operatorname{Norm}(v_i)\right)
$$

$v_i$ 是前序层输出，$w_l$ 是第 $l$ 层的可学习 pseudo-query。权重依赖当前 token 的层表示，因此不同 token 可以选择不同深度的特征。

Full AttnRes 需要保存全部 $L$ 层输出，状态量为 $O(Ld)$。Block AttnRes 将连续层划分为 $N$ 个 block：block 内仍使用普通残差累加，block 间只对汇总表示做 attention，将状态量降为 $O(Nd)$。原始 embedding 始终作为可检索表示保留。

AttnRes 的作用与 KDA 正交：KDA 在序列维度压缩历史 token，AttnRes 在深度维度选择历史层。前者控制长上下文复杂度，后者改善深层网络的信息与梯度分布。

## Stable LatentMoE

K3 包含 896 个专家，每个 token 选择 16 个专家，激活比例约为 1.8%。稀疏 MoE 的输出可写为：

$$
y = \sum_{i\in\operatorname{TopK}(g(x))}p_iE_i(x),
\qquad K=16
$$

$g(x)$ 是 router，$p_i$ 是归一化路由权重，$E_i$ 是专家网络。总参数量随专家数增长，而单 token 只执行被选中的子网络。

大规模 MoE 的主要问题是专家负载不均。若大量 token 集中到少数专家，会产生跨设备通信拥塞与计算空洞。Quantile Balancing 根据 router score 的分位数确定专家分配，避免依赖启发式负载更新和敏感的平衡超参数。

训练系统采用 fully balanced expert parallelism：各设备使用静态 tensor shape，并从关键执行路径移除 host synchronization，以降低 896 专家并行时的通信抖动。

## 训练与量化

### Per-Head Muon

Muon 使用矩阵正交化后的更新方向优化二维参数。K3 将其细化到 attention head，使不同 head 独立计算更新，减少大矩阵统一归一化造成的尺度耦合。

### SiTU 与 Gated MLA

Sigmoid Tanh Unit（SiTU）通过 sigmoid 与 tanh 的组合约束激活幅度。Gated MLA 在低秩 KV 表示之外增加可学习门控，控制不同 token 和 head 的 attention 输出。二者分别稳定激活值与注意力选择。

### 量化感知训练

K3 从 SFT 阶段开始进行 quantization-aware training，使用 MXFP4 权重和 MXFP8 激活。训练时显式模拟低精度数值误差，使模型适应量化后的权重分布，降低部署阶段直接 PTQ 带来的精度损失。

## 推理系统

KDA 不保存完整 KV 序列，但其递归状态改变了传统 prefix cache 的复用方式。Moonshot AI 为 vLLM 实现了 KDA prefill cache，使共享前缀可以缓存预填充后的状态。

2.8T MoE 的推理依赖大规模 expert parallelism。官方建议使用 64 张或更多加速卡组成的 supernode，以扩大高带宽通信域，减少跨节点专家路由开销。

## 局限

- K3 依赖完整 thinking history；Agent harness 遗漏历史 thinking 或中途切换模型会降低生成稳定性。
- 长程任务训练增强了模型的主动性。执行工程任务时需要明确文件范围、工具权限、停止条件与确认边界。
- 2.8T 稀疏 MoE 对显存容量和卡间通信提出较高要求，不适合常规单机部署。
